# Advanced GUI Calculator

## 📌 Project Overview
A feature-rich scientific and standard calculator built using Python and the `tkinter` library. It features a modern dark-themed user interface and supports both basic arithmetic and advanced mathematical operations.

## 🎯 Key Features
- **User-Friendly GUI:** Clean, responsive, and modern dark-themed interface built with `tkinter`.
- **Advanced Math Functions:** Supports trigonometric functions (sin, cos, tan), square roots, powers, and parentheses handling.
- **Robust Error Handling:** Prevents application crashes and handles invalid mathematical operations (like division by zero or syntax errors) gracefully.
- **Cross-Platform:** Developed and tested to run smoothly on both desktop environments and mobile Python IDEs (like Pydroid 3).

## 🛠️ Built With
- **Python 3**
- **Tkinter** (GUI Library)
- **Math Library**

## 🚀 How to Run
1. Clone this repository or download the `calculator.py` file.
2. Ensure Python 3 is installed on your system.
3. Run the script:
```bash
python calculator.py
